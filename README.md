# Derek

**LETZTE AUFNAHME** – Bodycam-Horrorspiel (eine einzige Datei: `public/index.html`, Three.js eingebettet).

Steuerung: WASD, Maus, Shift (rennen), C (ducken), F (Lampe), E (aufnehmen, verstecken, Tür öffnen), Esc (Pause), R (neu starten).

Ältere Spiele (Granny Horror, Gun Zone) sind in der Git-Historie (Commit 0f923b8) und im Repo `derek2` zu finden.
